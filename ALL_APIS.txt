BASE ENVIRONMENTS:
----------------------------------------------------------------------------------------------------
1. LOCAL DEVELOPMENT BASE URL:
   http://localhost:3000/api/v1

2. PRODUCTION / STAGING (RAILWAY) BASE URL:
   https://tradenexabackend-dev.up.railway.app/api/v1

3. WEBSOCKET / SOCKET.IO SERVER:

====================================================================================================
GLOBAL REQUEST & RESPONSE FORMATS
====================================================================================================

1. AUTHENTICATION HEADER:
   All authenticated APIs require the JWT access token in the HTTP Authorization header:
   Authorization: Bearer <access_token>

2. SUCCESS RESPONSE WRAPPER:
   {
     "success": true,
     "message": "Operation completed successfully",
     "data": { ... },
     "pagination": {          // (Included when endpoints are paginated)
       "page": 1,
       "limit": 20,
       "total_records": 150,
       "total_pages": 8
     }
   }

3. ERROR RESPONSE WRAPPER:
   {
     "success": false,
     "message": "Validation failed",
     "errors": [
       { "field": "mobile_number", "message": "Invalid mobile number. Must include country code prefix (e.g., +919876543210)" }
     ]
   }

4. USER ROLES (ROLE CODES):
   - buyer         : Standard Buyer
   - seller        : Standard Seller / Supplier
   - buyer_seller  : Dual Role (Can buy & sell)
   - admin         : Platform Admin
   - super_admin   : Super Administrator
   - supporter     : Customer Support Executive

5. DEVICE TYPES:
   - "android" | "ios" | "web"

MODULE 01: AUTHENTICATION & USER PROFILE (/auth)
====================================================================================================

----------------------------------------------------------------------------------------------------
1.1 SEND OTP
----------------------------------------------------------------------------------------------------
- METHOD: POST
- URL: /auth/send-otp
- AUTH: Public (No token required)
- HEADERS: Content-Type: application/json
- REQUEST BODY (JSON):
  {
    "mobile_number": "+919876543210",       // [Required] String with country code prefix (+91...)
    "recaptcha_token": "optional_token_str"  // [Optional] String
  }
- RESPONSE (200 OK):
  {
    "success": true,
    "message": "OTP sent successfully",
    "data": {
      "firebase_verification_id": "test_verification_id_or_firebase_id",
      "mobile_number": "+919876543210",
      "is_registered": true                  // If false, redirect user to Complete Registration Screen
    }
  }

----------------------------------------------------------------------------------------------------
1.2 VERIFY OTP
----------------------------------------------------------------------------------------------------
- METHOD: POST
- URL: /auth/verify-otp
- AUTH: Public (No token required)
- HEADERS: Content-Type: application/json
- REQUEST BODY (JSON):
  {
    "mobile_number": "+919876543210",               // [Required] String
    "otp": "123456",                                 // [Required] String / Number (4-8 digits)
    "firebase_verification_id": "verif_id_string",   // [Required] String
    "device": {                                      // [Optional] Object
      "device_type": "android",                      // "android" | "ios" | "web"
      "device_token": "fcm_push_token_string"
    }
  }
- RESPONSE (200 OK - If User Registered):
  {
    "success": true,
    "message": "OTP verified successfully",
    "data": {
      "is_registered": true,
      "access_token": "eyJhbGciOi...",
      "refresh_token": "eyJhbGciOi...",
      "user": {
        "id": 1,
        "full_name": "Rajesh Sharma",
        "email": "rajesh@example.com",
        "mobile_number": "+919876543210",
        "roles": ["buyer"],
        "is_completed_profile": true
      }
    }
  }
- RESPONSE (200 OK - If New User / Not Registered):
  {
    "success": true,
    "message": "OTP verified successfully",
    "data": {
      "is_registered": false,
      "registration_token": "temp_registration_jwt_token", // Send in Authorization header or body on register
      "mobile_number": "+919876543210"
    }
  }

----------------------------------------------------------------------------------------------------
1.3 RESEND OTP
----------------------------------------------------------------------------------------------------
- METHOD: POST
- URL: /auth/resend-otp
- AUTH: Public
- HEADERS: Content-Type: application/json
- REQUEST BODY (JSON):
  {
    "mobile_number": "+919876543210",
    "firebase_verification_id": "verif_id_string",
    "recaptcha_token": "optional_token"
  }
- RESPONSE (200 OK):
  {
    "success": true,
    "message": "OTP resent successfully",
    "data": {
      "firebase_verification_id": "new_or_existing_verif_id"
    }
  }

----------------------------------------------------------------------------------------------------
1.4 REGISTER (NEW USER ACCOUNT)
----------------------------------------------------------------------------------------------------
- METHOD: POST
- URL: /auth/register
- AUTH: Required (Send Registration Token in Authorization Header: Bearer <registration_token>)
- HEADERS: Content-Type: application/json
- REQUEST BODY (JSON):
  {
    "mobile_number": "+919876543210",       // [Required] Must match verified mobile
    "full_name": "Jatin Patel",              // [Required] 2-100 characters
    "email": "jatin@example.com",            // [Required] Valid email
    "role_id": 1,                            // [Required] 1 = Buyer, 2 = Seller, 3 = Buyer+Seller
    "business_type_id": 1,                   // [Required] From GET /business-types
    "language_id": 1,                        // [Optional] 1 = English, 2 = Hindi, 3 = Gujarati
    "device": {                              // [Optional]
      "device_type": "android",
      "device_token": "fcm_token_string"
    }
  }
- RESPONSE (201 Created):
  {
    "success": true,
    "message": "Registration successful",
    "data": {
      "access_token": "eyJhbGciOi...",
      "refresh_token": "eyJhbGciOi...",
      "user": {
        "id": 5,
        "full_name": "Jatin Patel",
        "email": "jatin@example.com",
        "mobile_number": "+919876543210",
        "roles": ["seller"],
        "is_completed_profile": false
      }
    }
  }

1.8 UPDATE / COMPLETE PROFILE
----------------------------------------------------------------------------------------------------
- METHOD: PUT
- URL: /auth/profile
- AUTH: Required (Bearer <access_token>)
- HEADERS: Content-Type: multipart/form-data
- FORM-DATA FIELDS:
  • File Uploads (Optional):
    - profile_image   : (File: jpg/jpeg/png/webp, max 5MB) User avatar
    - company_logo    : (File: jpg/jpeg/png/webp, max 5MB) Company logo
    - company_banner  : (File: jpg/jpeg/png/webp, max 10MB) Company profile banner

  • For Buyer Role (Text Fields):
    - company_name    : (String, 2-200 chars) [Required]
    - industry        : (String, 2-200 chars) [Required]
    - category_id     : (Integer) [Required] Main Category ID
    - gst_number      : (String) [Optional] 15-char GST format
    - address_line_1  : (String, 3-255 chars) [Required]
    - address_line_2  : (String) [Optional]
    - country_id      : (Integer) [Required] e.g. 1 (India)
    - state_id        : (Integer) [Required]
    - city_id         : (Integer) [Required]
    - pincode         : (String, 6 digits) [Required] e.g. "395006"

  • For Seller Role (Text Fields):
    - company_name         : (String, 2-200 chars) [Required]
    - category_id          : (Integer) [Required] Main Category ID
    - gst_number           : (String) [Required] Valid GST
    - pan_number           : (String) [Required] Valid PAN (ABCDE1234F)
    - business_description : (String, min 10 chars) [Required]
    - cin                  : (String) [Optional]
    - iec                  : (String) [Optional]
    - address_line_1       : (String, 3-255 chars) [Required]
    - address_line_2       : (String) [Optional]
    - country_id           : (Integer) [Required]
    - state_id             : (Integer) [Required]
    - city_id              : (Integer) [Required]
    - pincode              : (String, 6 digits) [Required]

  • For Buyer_Seller Dual Role (Text Fields):
    - Includes all fields of both Buyer & Seller above.

- RESPONSE (200 OK):
  {
    "success": true,
    "message": "Profile updated successfully",
    "data": { ...updated profile object... }
  }

- HEADERS: Content-Type: multipart/form-data

    - subcategory_id       : (Integer) [Required]

    - currency             : (String, e.g. "INR") [Required]

    - country_of_origin    : (String, e.g. "India") [Required]
    - product_condition    : ("new" | "used" | "refurbished") [Required]
    - stock_status         : ("in_stock" | "out_of_stock" | "made_to_order") [Required]
    - show_price           : ("true" | "false") [Required]
    - accept_inquiry       : ("true" | "false") [Required]
    - is_active            : ("true" | "false") [Required]

  • Optional Text Fields:
    - description          : (String, max 5000 chars) Full rich description
    - warranty             : (String, max 100 chars)
    - stock_quantity       : (Integer, min: 0)
    - hsn_code             : (String, max 20 chars)
    - gst_percentage       : (Float, 0 to 100, e.g. 5.0)
